# Kuarkcoin Starter
Ready-to-run Next.js 14 + Tailwind project for Kuarkcoin market news, financial data, and signal tracking.

## Quick Start
1. Install deps
```
npm install
```
2. Create `.env` from `.env.example` and set `DATABASE_URL` (Supabase/Postgres).
3. Run
```
npm run dev
```
Open http://localhost:3000
